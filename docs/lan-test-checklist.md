# Чек-лист локального теста в одной Wi-Fi сети

Wi-Fi играет роль корпоративной сети. Подготовка и адреса — в [web-testing-on-iphone.md](web-testing-on-iphone.md).

## Подготовка

- [ ] В `server/.env` стоит `DEV_MODE=false`, для смены дней — `TEST_CLOCK=true`.
- [ ] Запущен `./run-lan.sh --office-net`, в выводе есть ссылка на экран офиса `https://<ip>:6443/#key=...`.
- [ ] Админка открывается на Mac. Если она пишет «Сервер недоступен», в том же браузере откройте
      `https://<ip>:7443/healthcheck` и подтвердите сертификат: админка ходит в API на этот порт.
- [ ] В админке («Офисы») сеть офиса по умолчанию — подсеть Wi-Fi, например `10.20.30.0/24`.
- [ ] В админке («Ограничения») на время теста уменьшена пауза между заданиями (по умолчанию 30 мин)
      и проверены часы заданий (по умолчанию 08:00–20:00 по времени офиса).
- [ ] Созданы минимум 2 аккаунта игроков в одном офисе, в разных департаментах.

## Экран офиса на ноутбуке

Ссылку с ключом открывать только на ноутбуке, не на телефонах игроков. Если ноутбук — не тот Mac, где
запущен сервер, браузер предупредит о сертификате: либо установите CA с `http://<ip>:8080`, либо
подтвердите переход один раз.

- [ ] Вкладка «Вход и выход» показывает два QR-кода, полоса таймера идёт, коды меняются каждые 30 с.
- [ ] Вкладка «Комнаты» показывает 14 кодов (3 и 5 этаж), код увеличивается по нажатию.

## Телефоны

- [ ] На каждом телефоне установлен и включён сертификат CA, игра `https://<ip>:8443` открывается.
- [ ] Вход по логину и паролю работает. Неверный пароль даёт ошибку, самостоятельной регистрации нет.
- [ ] Разрешения на камеру и датчики движения выдаются, камера показывает превью.

## Присутствие в офисе

- [ ] До кода входа задания и код комнаты не засчитываются.
- [ ] Скан кода ВХОД с ноутбука: игрок «в офисе», засчитано задание «Отметиться», начислены коины.
- [ ] Повторный скан того же кода ВХОД отклонён (`presence_token_reused`).
- [ ] Фото кода ВХОД, отсканированное позже 60 с, отклонено (`presence_token_invalid`).
- [ ] Скан кода комнаты: персонаж переходит в эту комнату, при коде с другого этажа меняется этаж.
- [ ] Скан кода ВЫХОД: задания и коды комнат больше не засчитываются до нового входа.

## Сеть офиса

- [ ] В админке временно поставить чужую сеть (`10.0.0.0/24`): игровые действия на телефонах дают
      `office_network_required`, попытка видна в журнале подозрительных действий.
- [ ] Вернуть подсеть Wi-Fi: игра снова работает.
- [ ] Телефон на мобильном интернете (Wi-Fi выключен) не открывает игру.

## Задания

- [ ] Одиночные задания с камерой и датчиками: найти предмет, приседания, лестница, селфи с улыбкой,
      нота, скороговорка, охота за метками. Каждое засчитывается один раз, коины приходят.
- [ ] Пропуск задания работает, выданное взамен задание отображается.
- [ ] Пауза между заданиями соблюдается: следующее задание недоступно до её окончания.
- [ ] Совместное фото: первый игрок начинает, второй подтверждает во входящих, оба получают награду.
- [ ] «Слепой кофе» и «Бинго коллег»: скан «Мой QR» второго игрока засчитывается.
- [ ] Коллегу из другого офиса назначить нельзя.

## Экономика и лимиты

- [ ] Баланс совпадает с историей операций в админке (статистика игрока).
- [ ] Покупка в магазине и гардеробе списывает коины. При нехватке коинов покупка отклоняется.
- [ ] Повторная отправка покупки (двойное нажатие, плохая сеть) не списывает коины дважды.
- [ ] После лимита непрерывной игры появляется предупреждение, затем отдых. Идущую мини-игру лимит
      не прерывает.

## Смена дней (вкладка «Время» в админке, нужен `TEST_CLOCK=true`)

- [ ] «Следующий рабочий день, 09:00»: в игре после обновления экрана новый день и новый набор заданий.
- [ ] Два рабочих дня подряд дают разные задания: за пару дней игрок получает все задания.
- [ ] В выходной в игре только «Отметиться» и надпись «Сегодня выходной: заданий нет».
- [ ] Пропуск рабочих дней без входа в офис: серия обнуляется, со второго пропущенного дня списывается штраф.
- [ ] Статистика игрока в админке показывает дни, задания и коины по датам.
- [ ] «Вернуть настоящее время» в конце теста.

## Админка

- [ ] Видны оба игрока, их активность и статистика по департаментам.
- [ ] После блокировки следующее действие игрока отклоняется, войти снова нельзя. После разблокировки вход работает.
- [ ] Командировка: игрок засчитывает код входа только того офиса, куда он командирован.
