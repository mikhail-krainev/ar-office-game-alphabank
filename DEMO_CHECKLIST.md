# Чек-лист демонстрации «Альфа Офис»

Полная проверка сервиса вживую: сервер, админка, панель руководителя, экран у ресепшна, игра на
телефонах в Wi-Fi «офиса». Пункты идут в порядке демонстрации: от подготовки до игрового дня, админки
и антифрода. Напротив каждого пункта указан ожидаемый результат. Отмечайте галочку, только если
результат совпал; расхождения записывайте в «Журнал ошибок» в конце.

Подробности запуска: [README.md](README.md) («Запуск»), [docs/web-testing-on-iphone.md](docs/web-testing-on-iphone.md),
краткий технический прогон: [docs/lan-test-checklist.md](docs/lan-test-checklist.md).

## Роли и оборудование

| Роль | Что нужно |
|---|---|
| Ведущий | Mac с сервером (Docker), админка в браузере, проектор или второй экран |
| Экран ресепшна | Ноутбук или монитор с открытым экраном офиса (коды «Вход» и «Выход») |
| Игрок A | Телефон (желательно iPhone, Safari), аккаунт в офисе по умолчанию, департамент 1 |
| Игрок B | Второй телефон (желательно Android, Chrome), тот же офис, департамент 2 |
| Игрок C (по желанию) | Третий телефон, третий департамент — для «Бинго знакомств» |
| Руководитель | Любой браузер, аккаунт руководителя с доступом к офису |

Расходники: распечатанные эмблемы комнат (на двери или стены), метки ArUco, 3–4 предмета для
«Найди предмет» (кружка, мышь, ручка, бутылка), бумага для «Бумажного баскетбола» не нужна (AR),
зарядки для телефонов, Wi-Fi роутер или точка доступа, к которой подключены все устройства.

## 1. Подготовка за день

- [ ] `git pull` на Mac, ветка `main`, рабочее дерево чистое.
- [ ] В `server/.env`: `APP_ENV=dev` (консоль со всеми командами — страховка на демо), `DEV_MODE=false`
      (иначе dev-RPC раздают код входа любому игроку), `TEST_CLOCK=true` не обязателен: в dev часы включены.
- [ ] Эмблемы и метки распечатаны: `python tools/printables/make_printables.py --out build/printables`.
      Эмблемы развешаны по «комнатам» площадки, на каждой подписана комната.
- [ ] `./run-lan.sh --office-net` запускается без ошибок, в выводе ссылка на экран офиса
      `https://<ip>:6443/#key=...`, предупреждение про `APP_ENV`, но не про `DEV_MODE`.
- [ ] На каждом телефоне установлен и включён сертификат CA (`http://<ip>:8080`), игра
      `https://<ip>:8443` открывается без предупреждения.
- [ ] Админка открывается на Mac. Если «Сервер недоступен» — открыть `https://<ip>:7443/healthcheck` в
      том же браузере и подтвердить сертификат.
- [ ] Прогон тестов: `go test ./...` в `server/modules`, GdUnit4 клиента, `npm run build` в `admin` —
      всё зелёное (команды в README, «Тесты и проверки»).
- [ ] Генеральный прогон всего чек-листа один раз пройден, найденное починено.

## 2. Подготовка за час до показа

- [ ] Сервер поднят (`docker compose ps`: nakama и postgres `healthy`).
- [ ] Админка — «Офисы»: у офиса по умолчанию сеть = подсеть Wi-Fi площадки (например `10.20.30.0/24`).
- [ ] Админка — «Ограничения»: пауза между заданиями уменьшена до 1–2 мин, часы заданий захватывают
      время показа, лимит непрерывной игры не сработает случайно (или наоборот уменьшен, если его показываем).
- [ ] Админка — «Доступ»: аккаунты игроков A, B (и C) в одном офисе, в разных департаментах. Логины и
      пароли записаны на карточках.
- [ ] Админка — «Руководители»: аккаунт руководителя с доступом к офису, права создавать и удалять.
- [ ] Консоль: `status` — окружение `dev`, игроков сколько ожидается; `time` — сдвиг часов 0
      (если нет — `time_reset`).
- [ ] Консоль: для каждого игрока `reset_day <логин>` — день начинается с чистого листа. Если нужен
      розыгрыш: `office_days <логин> 8` и `give_coins <логин> 2000` для покупки билета.
- [ ] Телефоны: яркость на максимум, автоблокировка выключена, «Не беспокоить» включён, уведомления
      браузера для игры разрешены.
- [ ] Экран ресепшна открыт на ноутбуке и виден игрокам.

## 3. Экран у ресепшна

- [ ] Вкладка «Вход и выход»: два QR-кода, полоса таймера идёт, коды меняются каждые 30 с.
- [ ] Вкладка «Комнаты»: эмблемы всех дверей (3 и 5 этаж), эмблема увеличивается по нажатию.

## 4. Вход в игру (телефоны A и B)

- [ ] Неверный пароль — отказ с просьбой обратиться к администратору. Кнопки регистрации нет.
- [ ] Верный логин и пароль — игра входит. Первый вход: приветственный бонус 300 коинов.
- [ ] Разрешения на камеру и датчики движения запрашиваются и выдаются (на iPhone — по касанию).
- [ ] iPhone: игра на весь экран, без чёрных полей; портретная ориентация.

## 5. Утро и квартира (можно вне Wi-Fi офиса)

- [ ] Катсцена утра: будильник, умывание, завтрак; показана серия и множитель наград.
- [ ] Квартира: нажатие на карту — персонаж идёт в обход мебели; удержание — идёт за пальцем.
- [ ] Предметы мебели отвечают репликами персонажа.
- [ ] «Гардероб»: смена кожи, волос, верха, низа, обуви; образ сохраняется после перезахода.
- [ ] «Гараж»: выбор машины; машина, которой нет, покупается за коины или недоступна по цене.
- [ ] «Интерьер»: купить предмет мебели, поставить на карту. Зелёная подсветка там, где помещается,
      красная — где перекроет проход. «Переставить предметы» переносит и убирает предмет. После
      перезахода расстановка та же.
- [ ] «Интерьер» — «Палитра»: перекрашивает пол и стены, узоры остаются.
- [ ] Телефон на мобильном интернете (Wi-Fi выключен): квартира, гардероб, гараж, профиль работают;
      «Поехать в офис» открывает экран «Офис ещё закрыт». После включения Wi-Fi офиса экран сам
      пропускает в поездку (проверка раз в 10 с) или по кнопке «Проверить снова».

## 6. Дорога и приход в офис

- [ ] Катсцена дороги: двор, трасса, пробка, парковка; машина в катсцене — выбранная в гараже.
- [ ] В офисе сразу открывается сканер кода входа (автоматическая отметка).
- [ ] Закрыть сканер, не сканируя: висит кнопка «Отсканируй QR входа», в админке у игрока видно время
      прихода по Wi-Fi, задания не засчитываются.
- [ ] Скан кода «Вход» с экрана ресепшна: засчитано «Отметиться на ресепшне», начислены коины,
      игрок «в офисе».
- [ ] Повторный скан того же кода — отказ `presence_token_reused`.
- [ ] Фото кода «Вход», отсканированное позже 60 с, — отказ `presence_token_invalid`.
- [ ] После отметки предлагает написать факты для «Три правды, две лжи» (если задание в наборе).

## 7. Офис: карта и коллеги

- [ ] По карте ходят NPC, разговоры с ними в облачках.
- [ ] Персонаж второго игрока (B) виден на карте у A в его наряде, с ником и аватаркой.
- [ ] Нажатие на коллегу — мини-профиль: аватар, департамент, статус, серия.
- [ ] Список заданий справа: набор на сегодня, сложные с меткой x2/x3, награды.

## 8. Задания: взятие по эмблеме комнаты

Новое поведение: персонаж к месту задания не идёт, мини-игра стартует сразу после скана.

- [ ] Выбрать задание в списке, когда последняя эмблема — другая комната: вопрос «Задание ждёт в
      комнате…», кнопка сканирования.
- [ ] Скан эмблемы нужной комнаты: мини-игра открывается сразу, персонаж не ходит.
- [ ] То же для задания на другом этаже (5 этаж, аналитика): мини-игра сразу, без лифта.
- [ ] Скан эмблемы чужой комнаты на вопрос — «Это другая эмблема. Нужна эмблема комнаты …».
- [ ] Кнопка «QR», эмблема комнаты с одним открытым заданием — задание берётся и стартует сразу.
- [ ] Кнопка «QR», эмблема комнаты с несколькими открытыми заданиями — список только этих заданий,
      выбор запускает мини-игру.
- [ ] Кнопка «QR», эмблема комнаты без открытых заданий — персонаж идёт в эту комнату (лифт, если этаж другой).
- [ ] Эмблема до кода «Вход» или после кода «Выход» не засчитывается.

## 9. Мини-игры

Каждое задание засчитывается один раз, коины приходят с анимацией, баланс растёт. Пропустить можно
только сложные задания.

| Задание | Проверка | Готово |
|---|---|---|
| Найди предмет | Камера находит 3 предмета, рамка следует за предметом, вспышка при находке | [ ] |
| Утренняя зарядка | 10 приседаний, неоновый скелет, «+1» за каждое | [ ] |
| Лестница, не лифт | 120 шагов за 5 минут, счётчик шагов растёт при ходьбе | [ ] |
| Скороговорка | Две скороговорки вслух распознаются (нужен интернет на телефоне) | [ ] |
| Охота на баги | Баги вокруг, вид поворачивается гироскопом, стрелка у края, ловля касанием | [ ] |
| Бумажный баскетбол | AR-урна, бросок свайпом, ветер, 5 попаданий | [ ] |
| Повтори позу | Телефон на столе, 4 позы золотого силуэта, кольцо заполняется | [ ] |
| Маска кота | Маска держится на лице, команды: улыбка, подмигнуть, открыть рот, наклон | [ ] |
| Настроение дня | Рисунок на лбу, «Сделать фото», у B история с розовым кольцом на аватарке | [ ] |
| Фото с коллегой (A и B) | Сервер назначает B, двое в кадре, очки на лицах. У A «Ждёт», у B запрос во входящих. «Да» — A получает награду, B бонус 10 | [ ] |
| Фото с коллегой, отказ | B жмёт «Нет» — задание у A снова открыто, попытка в антифроде | [ ] |
| Три правды, две лжи | A отправляет факты B, B отмечает правду во входящих, A сканирует «Мой QR» B, бонус зависит от неугаданного | [ ] |
| Кофе вслепую (5 этаж) | Назначен коллега из другого департамента, 3 минуты, скан «Мой QR» | [ ] |
| Бинго знакомств (5 этаж) | Коды трёх коллег из трёх разных чужих департаментов (нужен игрок C) | [ ] |
| Объясни свою работу (5 этаж) | По две минуты рассказа, затем код коллеги | [ ] |
| Запасной вариант | Отказать в камере — запускается экранная версия с пометкой; отметка и фото с коллегой без камеры недоступны | [ ] |

- [ ] Скриншот «Мой QR» коллеги не засчитывается: код живёт не дольше 20 с.
- [ ] Пропуск сложного задания: подтверждение, задание закрыто до конца дня без награды.
- [ ] Пауза между заданиями: следующее задание заблокировано, на кнопке время до открытия.

## 10. Магазин, колесо, розыгрыш

- [ ] Магазин: 6 предметов дня, возможна скидка. Покупка списывает коины, при нехватке — отказ.
- [ ] Купленный мерч появляется в гардеробе, в магазине помечен «Уже есть».
- [ ] Промокод выдаётся сразу; эпическая или легендарная награда уходит на подтверждение (видно в админке).
- [ ] Двойное нажатие «Купить» при плохой сети не списывает коины дважды.
- [ ] Награда с исчерпанным запасом показана «Нет в наличии» (запас уменьшить в «Награды» или `set_stock`).
- [ ] Колесо фортуны: спин за 300, колесо докручивается до сектора, выбранного сервером; шансы под колесом.
- [ ] Выпала вещь, которая уже есть, — выбор: повторный спин или монеты.
- [ ] Розыгрыш парковки: условие 8 дней в офисе за 30 дней; без него билет не купить.
- [ ] Покупка билета (1 500), игрок в списке участников, идёт обратный отсчёт.
- [ ] Консоль `raffle_draw <логин>`: рулетка с аватарками останавливается на победителе, победителю
      уведомление, остальным — итог. В консоли `raffle <логин>` показывает победителя.

## 11. Профиль и уведомления

- [ ] Профиль: смена аватара на готовый портрет и на фото из галереи (обрезка 64×64).
- [ ] Статус до 60 символов сохраняется и виден коллегам в мини-профиле.
- [ ] Календарь посещений: сегодняшний день отмечен, по нажатию — задания дня.
- [ ] Колокольчик: число непрочитанных, запросы на фото, итоги розыгрыша.
- [ ] Баннер сверху при новом событии, пока игра открыта.

## 12. Рабочее время и лимит игры

- [ ] Вне часов заданий задания не засчитываются, кнопки показывают время открытия.
- [ ] Консоль `play_state <логин> warning`: предупреждение с таймером на 5 минут.
- [ ] «Отдохнуть сейчас» — экран отдыха с часами; по окончании — «Вернуться в игру».
- [ ] `play_state <логин> blocked`: экран «На сегодня вы провели слишком много времени в игре!».
- [ ] Лимит наступает во время мини-игры: плашка «Спокойно доиграйте», результат засчитан, отдых после.
- [ ] Консоль `play_state <логин> ok` возвращает игру.

## 13. Сеть офиса (антифрод)

- [ ] Админка — «Офисы»: временно поставить чужую сеть (`10.0.0.0/24`). Офисные действия на телефоне —
      экран «Только в офисе», запросы отклоняются `office_network_required`, попытка в антифроде.
- [ ] Вернуть подсеть Wi-Fi: игра продолжается с того же места.
- [ ] Сеть другого офиса пересекается с текущей — админка не сохраняет (`networks_overlap`).

## 14. Вечер

- [ ] Скан кода «Выход»: задания и эмблемы больше не засчитываются.
- [ ] «Поехать домой» с открытыми заданиями — подтверждение; персонаж выходит через двери, катсцена
      вечера, ночь, сон, новое утро.

## 15. Смена дней (консоль или вкладка «Время»)

- [ ] `time_add 1d` (или «Следующий рабочий день, 09:00»): после обновления экрана новый день, новый
      набор заданий, другой, чем вчера.
- [ ] Выходной: только «Отметиться» и «Сегодня выходной: заданий нет».
- [ ] Пропуск двух рабочих дней без входа: утром сгоревшая серия и штраф 3%, уведомление о штрафе.
- [ ] Серия и множитель растут при входе несколько рабочих дней подряд (`office_days` для быстрого показа).
- [ ] `time_reset` в конце блока: настоящее время.

## 16. Админка

- [ ] Вход админа; неверный пароль — «Неверный логин или пароль».
- [ ] «Доступ»: создать игрока (пароль генерируется, департаменты только выбранного офиса), панель
      показывает логин и пароль. Новый игрок входит в игру.
- [ ] Смена офиса и департамента в строке, смена пароля (старый перестаёт работать).
- [ ] Блокировка: следующее действие игрока отклоняется, войти нельзя. Разблокировка: вход работает,
      дни блокировки не штрафуются.
- [ ] Командировка в другой офис: в строке видна, игрок засчитывает код только того офиса; досрочное завершение.
- [ ] «Офисы»: добавить офис, сеть, департамент; переименовать департамент.
- [ ] «Статистика»: счётчики «сейчас в офисе», «были сегодня»; поиск, фильтры, сортировка.
- [ ] Аудит игрока: карточка, календарь, «По дням» (приход, уход, задания, коины), журнал действий с
      фильтром, монеты (совпадают с балансом в игре), антифрод (сканы с повтором, чужая сеть, отказ фото).
- [ ] «Награды»: запас по неделям, сколько выдано через магазин и колесо, изменение запаса.
- [ ] «Ограничения»: смена паузы действует со следующего действия игрока; «Значения по умолчанию».
- [ ] Удаление тестового игрока.

## 17. Консоль админки

- [ ] Бейдж окружения: `DEV: все команды`. `help` — список, `help give_coins` — описание.
- [ ] Tab дополняет имя команды, ↑/↓ листают историю, подсказки под строкой, `clear` очищает.
- [ ] Просмотр: `status`, `find тест`, `player <логин>`, `tasks <логин>`, `ledger <логин> 5`,
      `activity <логин> 5`, `offices`, `items`, `stock`.
- [ ] `give_coins <логин> 500`: баланс в игре вырос, в `ledger` строка `admin_console`, в журнале
      действий игрока — «Команда админ-консоли» со строкой команды.
- [ ] `complete_task <логин> <id>` и `reset_task`: задание в игре закрывается и снова открывается.
- [ ] `check_in <логин>`, `room <логин> <комната>`, `check_out <логин>`: статус в админке меняется.
- [ ] Ошибки понятны: неизвестная команда, неизвестный логин, неверное число.
- [ ] Только просмотр в prod (по желанию, в конце): `APP_ENV=prod`, `docker compose up -d`, бейдж
      `PROD: только просмотр`, `give_coins` отвечает «работает только с APP_ENV=dev». Вернуть `dev`.

## 18. Панель руководителя

- [ ] Вход руководителя по тому же адресу открывает его панель, а не админскую.
- [ ] Статистика — только сотрудники из его доступа; аудит игрока тот же экран.
- [ ] Создание сотрудника в своём департаменте работает; в чужом — недоступно.
- [ ] Администратор отбирает право создавать — следующая попытка руководителя `manager_right_missing`.
- [ ] Удаление сотрудника (если право есть).

## 19. Устойчивость

- [ ] Перезагрузка страницы игры посреди дня: прогресс тот же, вход по сохранённой сессии.
- [ ] Вход тем же аккаунтом на другом телефоне: тот же баланс, задания, интерьер.
- [ ] Выход из профиля и вход другим игроком на том же телефоне.
- [ ] `docker compose restart nakama`: после перезапуска игра и админка продолжают работать, данные на месте.

## План Б на демо

| Если | Делаем |
|---|---|
| Мини-игра не распознаёт (свет, камера) | Показать запасной вариант или `complete_task <логин> <id>` в консоли |
| Нет второго человека для совместного задания | Второй телефон у ведущего; `check_in <логин>` для B |
| Пауза между заданиями мешает | `reset_cooldown <логин>` или `task_limits <логин> off` |
| Не хватает коинов на покупку или билет | `give_coins <логин> <N>` |
| Нужно показать завтрашний день | `time_add 1d`, в конце `time_reset` |
| Телефон не видит сервер | Проверить Wi-Fi, сертификат CA, `https://<ip>:7443/healthcheck` |
| Сломалось всё | Скриншоты из `docs/screenshots` и запись генерального прогона |
