# Бренд-ассеты

`alfa_mark_small.png` и `alfa_mark_large.png` — упрощённая пиксельная стилизация знака Альфа-Банка, сгенерированная `tools/generate_placeholder_art.gd`.

Товарный знак принадлежит АО «Альфа-Банк». Он используется только в учебном концепте, который нигде не публикуется, и не подпадает под лицензию репозитория. Для показа за пределами учебного проекта нужен официальный логотип из брендбука и разрешение правообладателя.
