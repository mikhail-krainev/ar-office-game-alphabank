# Бренд-ассеты

`alfa_mark_small.png` и `alfa_mark_large.png` — упрощённая пиксельная стилизация знака Альфа-Банка, сгенерированная `tools/generate_placeholder_art.gd`.

`emblems/` — эмблемы дверей комнат вместо QR-кодов: версии логотипа и стикеры с котом из айдентики Альфа-Банка, присланные владельцем проекта как референсы. Картинки приведены к белому фону и стороне до 384 px; `logo_night` и `logo_mono` — белая и чёрная версии логотипа, перекрашенные из `logo_red`. `emblems.json` связывает эмблему с комнатой, его читают игра (`RoomEmblems`), экран офиса и скрипт печати.

Товарные знаки, логотип и стикеры принадлежат АО «Альфа-Банк». Они используются только в учебном концепте, который нигде не публикуется, и не подпадают под лицензию репозитория. Для показа за пределами учебного проекта нужен официальный логотип из брендбука и разрешение правообладателя.
